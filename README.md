# 똑똑 수학탐험대 · 분수의 곱셈 탐험

분수 막대·원 모형·다각형 모형을 **끌어서 옮기며** 분수의 곱셈 원리를 익히는 웹앱입니다.
교사와 학생이 분자·분모·자연수를 자유롭게 바꿀 수 있습니다.

## 학습 흐름

처음 화면에서 **진분수 × 자연수 / 자연수 × 진분수 / 대분수 × 자연수** 중 하나를 고르면 4단계로 이어집니다.
(화면에는 학생용 표현만 쓰고, 괄호 안은 교사용 설명입니다.)

| 단계 (화면 표시) | 내용 |
|---|---|
| 1 생각해 볼까요? (동기유발) | 유형별 선택형 질문 5~6개 → 마지막 ★카드에서 "모형으로 직접 해 볼래요" 버튼으로 다음 단계로 이어짐 |
| 2 모형으로 해 볼까요? (구체적 조작) | 모형 조각을 '모으는 곳'으로 끌어 옮기기 (조각 하나씩 또는 손잡이로 통째로) |
| 3 덧셈으로 알아볼까요? (동수누가) | 같은 수를 여러 번 더하는 식 + 수직선 뛰어 세기 |
| 4 몇 배일까요? (배의 개념) | ○의 □배로 해석하기, "곱하면 항상 커질까?" 실험, 스스로 풀어 보기 |

### 1단계 질문 구성

- 공통: 4 × 2의 뜻 → 4의 1배
- 자연수 × 진분수: 4의 절반 → 절반을 분수로 → 4 × 1/2의 뜻 → 곱셈은 항상 커질까?
- 진분수 × 자연수: 색칠한 부분의 분수 → 2/5 × 3의 뜻 → 1/5이 몇 개? → 답이 2/5보다 클까?
- 대분수 × 자연수: 1 2/5는 어떤 수? → 1 2/5 × 3의 뜻 → 꽉 찬 1은 몇 개? → 분수 부분의 합은?
- 틀린 보기를 누르면 빨갛게 흔들리고, 정답을 고르면 그림과 설명이 나타납니다

## 지원 유형

- **진분수 × 자연수** (예: 2/5 × 3)
- **자연수 × 진분수** (예: 3 × 2/5 → "3의 2/5": 3을 5묶음으로 나눈 것 중 2묶음)
- **대분수 × 자연수** (예: 1 2/5 × 3 → 자연수·분수 따로 / 가분수로 바꾸기 두 방법)
- `⇄ 곱하는 순서 바꾸기` 버튼으로 진분수×자연수 ↔ 자연수×진분수 전환
- 모으는 곳의 **전체 1의 개수(막대 길이)** 를 1, 2, 3 … 으로 늘리고 줄일 수 있음

## 모바일 · 태블릿 지원

- 화면 폭에 맞춰 모형 크기와 배치를 다시 계산합니다 (휴대폰에서도 조각과 글자가 작아지지 않음)
- 손가락으로 조각·모형을 끌어 옮길 수 있습니다. 조각을 잡으면 스크롤이 멈추고, 빈 곳을 밀면 화면이 스크롤됩니다
- 여러 학생이 동시에 화면을 짚어도 처음 잡은 손가락만 따라갑니다
- 화면을 가로/세로로 돌리면 그림이 자동으로 다시 맞춰집니다
- 버튼은 손가락으로 누르기 쉬운 크기로 커집니다
- **홈 화면에 추가**하면 앱처럼 전체 화면으로 열립니다 (GitHub Pages 주소에서)
  - iPad/iPhone: Safari → 공유 → 홈 화면에 추가
  - Android/갤럭시 탭: Chrome → ⋮ → 홈 화면에 추가 / 앱 설치
- 한 번 열어 둔 뒤에는 인터넷이 끊겨도 열립니다 (서비스 워커 캐시)

## 파일 구성

```
index.html              ← 웹앱 본체 (단일 파일, 외부 라이브러리 없음)
manifest.webmanifest    ← 홈 화면 추가(앱 설치) 정보
sw.js                   ← 오프라인 캐시
icons/                  ← 앱 아이콘
apps-script/Code.gs     ← Google Apps Script 웹앱용
apps-script/Index.html  ← Apps Script용 HTML (manifest·오프라인 기능 제외)
.nojekyll
```

> 파일을 고친 뒤 학생 기기에 바로 반영되지 않으면 `sw.js`의 `CACHE` 이름 끝 숫자(v1 → v2)를 올려 주세요.

## GitHub Pages로 공개하기

1. 이 폴더 내용을 새 저장소에 올립니다.
   ```bash
   git init
   git add .
   git commit -m "분수의 곱셈 탐험 웹앱"
   git branch -M main
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```
2. 저장소 **Settings → Pages → Branch: `main` / `/(root)`** 를 선택하고 저장합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## Google Apps Script로 공개하기 (선택)

1. script.google.com → 새 프로젝트 → `apps-script/Code.gs` 내용 붙여넣기
2. 파일 추가(HTML) → 이름 `Index` → `apps-script/Index.html` 내용 붙여넣기
3. 배포 → 새 배포 → 웹 앱 → 액세스 권한 설정 후 배포

## 수의 범위

분모 2~10, 분자 1~(분모−1), 곱하는 자연수 1~9 (대분수는 1~5), 대분수의 자연수 부분 1~3
